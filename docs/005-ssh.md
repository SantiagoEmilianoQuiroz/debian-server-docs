# SSH

OpenSSH is used to remotely administer the Linux server.

The project includes:
- SSH server installation
- SSH service management
- SSH key authentication
- Remote command execution
- Basic SSH hardening
- Root login restrictions

### Example:

```
ssh admin@<server-ip>

```

### SSH key authentication:

```
ssh-keygen -t ed25519

```

## SSH Keys

step 1: In the principal machine run 

```
ssh-keygen -t ed25519

```

step 2: copy the key

```
ssh-copy-id admin@XXX.XXX.X.XXX
```

step 3: login width ssh

```

ssh admin@XXX.XXX.X.XXX

```
